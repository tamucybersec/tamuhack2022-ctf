# Gerardo's Bio 2

## Description

Gerardo recently started using twitter [twitter](https://twitter.com/gerardo_2001_), but he hasn't filled out his bio yet. He's recently gotten into astrology and wants to include his Mars sign in his bio. Can you help him out? 

The flag is in the format of gigem{sign_degrees_minutes_seconds} 

Example: Aquarius 8°00'44" is gigem{aquarius_8_00_44}

## Solution
In this sequel challenge, we have to find Gerardo’s astrology Mars sign. Through searching online, we can find that one’s Mars sign is an astrology fortune telling of sorts that is determined by birth date, time, and location. If we look for a [Mars sign calculator](https://cafeastrology.com/whats-my-mars-sign.html), we can input Gerardo’s birth day and time: [December 23rd](https://twitter.com/gerardo_2001_/status/1474055931138871306?s=20) 2001 (from Twitter handle), [8 AM assuming 00 minutes](https://twitter.com/gerardo_2001_/status/1477823900591529984?s=20), and [San Antonio](https://twitter.com/gerardo_2001_/status/1481405190267981831?s=20) through [reverse image search](https://images.google.com/). To arrive at Pisces 10° 43' 10". The flag, in format, is `gigem{pisces_10_43_10}`.
